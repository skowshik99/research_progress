The issue is that when `get_order_by()` tries to relabel an ordering column to a raw number, it looks for the ordering column in `self.select`. But `self.select` only contains `order`, not `pk`. So it fails.

The fix should be to add the ordering columns to `self.select` before calling `get_order_by()`. Or alternatively, we need to handle the case where the ordering column is not in the select list differently for combined queries.

For a non-union query, the SELECT clause would include all fields (if no `.values()` was called), so `pk` would be in the SELECT clause. But for a union query with `.values_list()`, the SELECT clause only includes the explicitly selected columns.
