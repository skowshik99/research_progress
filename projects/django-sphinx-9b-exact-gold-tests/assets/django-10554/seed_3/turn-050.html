The problem is that when we have:
1. A union query where the original select list was all columns (from `qs1.union(qs2)`)
2. Then `.values_list('order', flat=True)` is called, which limits the select to just `order`
3. Then `.order_by('-pk')` is called, which adds `-pk` to the ordering

- `get_combinator_sql()` is called
- It creates compilers for each combined query
- For each compiler, it checks if `compiler.query.values_select` is empty - but it's NOT empty because the combined queries still have their original select fields!
- So the sync doesn't happen
