1. I read the full file and emit the event

The problem is that I'm reading the file twice - once for the source-read event, and once by the parent class. The second read overwrites the modified content.

    }

        ret.append(wrappernode)
        return ret

    Like the standard "Include" directive, but interprets absolute paths
    "correctly", i.e. relative to source directory.

    the 'literal' option is specified).

        self.arguments[0] = filename

        if 'literal' not in self.options:
            # Read the full file content first to emit source-read event
            try:
                include_file = io.FileInput(
                    source_path=filename,

                    error_handler=self.state.document.settings.input_encoding_error_handler

                rawtext = include_file.read()
                include_file.close()

                docname = self.env.path2doc(filename)

                    pass

                    arg = [rawtext]
                    self.env.events.emit('source-read', docname, arg)

                    source_path=filename,

                    error_handler=self.state.document.settings.input_encoding_error_handler
