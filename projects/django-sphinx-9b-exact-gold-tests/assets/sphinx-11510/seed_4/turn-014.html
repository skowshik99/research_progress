Now I understand the issue. The `Include` directive in docutils reads the included file and inserts it into the document using `self.state_machine.insert_input(include_lines, path)`. This inserts the content as input to be parsed later.

The problem is that when Sphinx processes an include directive, it doesn't trigger the `source-read` event for the included file. The `source-read` event is only triggered for the main document being parsed, not for files that are included via the `.. include::` directive.
