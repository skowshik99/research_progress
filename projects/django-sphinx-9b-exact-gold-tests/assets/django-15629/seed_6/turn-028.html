Now I need to understand how the FK column gets its type and collation. Looking at the code, I see that:

1. `ForeignKey.db_parameters()` doesn't include collation
2. When creating a FK column, it uses `column_sql` which calls `field.db_parameters(connection=self.connection)` 
3. The `_iter_column_sql` method checks for collation in `field_db_params.get("collation")`

The issue is that when a ForeignKey points to a PK with a specific collation, the FK column should inherit that collation. This needs to be fixed in two places:

1. **For CreateModel**: When creating a model with a FK to a PK with db_collation, the FK column should get the collation from the referenced PK field.

2. **For AlterField**: When altering a PK's db_collation, any FKs pointing to it should have their collation updated.
