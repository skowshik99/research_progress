Let me look at the `__len__` method of `DataVariables` again:

```python
def __len__(self) -> int:
    return len(self._dataset._variables) - len(self._dataset._coord_names)
```

This assumes that all coordinate names are present in `_variables`, but this isn't always true. The fix should be to count only those variables that are not in `_coord_names`:

```python
def __len__(self) -> int:
    return sum(1 for key in self._dataset._variables if key not in self._dataset._coord_names)
```

Or alternatively:
```python
def __len__(self) -> int:
    return len(self._dataset._variables) - len(set(self._dataset._coord_names) & set(self._dataset._variables))
```
