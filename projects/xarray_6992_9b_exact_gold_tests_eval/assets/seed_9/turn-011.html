   - `dropped`: names that should not appear in variables after reset
   - `converted`: names that should be converted from IndexVariable to base Variable
   - `renamed`: old_name -> new_name mappings for renamed coordinates

- Should drop 'x', 'foo', and 'bar' from variables (they're all part of the multi-index)

- No renames
