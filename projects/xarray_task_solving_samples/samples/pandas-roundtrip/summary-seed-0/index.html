### get_index() Behavior (Step 6, common.py:453-461)
```python
def get_index(self, key: Hashable) -> pd.Index:
    if key not in self.dims:
        raise KeyError(key)
    try:
        return self._indexes[key].to_pandas_index()
    except KeyError:
        return pd.Index(range(self.sizes[key]), name=key)
```

| Condition | Return Value |
|-----------|--------------|
| Index exists in `_indexes` | `self._indexes[key].to_pandas_index()` |
| Index doesn't exist | `pd.Index(range(self.sizes[key]), name=key)` |

For `PandasIndex`, `to_pandas_index()` returns `self.index` (Step 10, indexes.py:343).

### Index Name Relationship (Steps 11-12)
Runtime verification showed:

| Case | Series Index Name | Index Type |
|------|-------------------|------------|
| With coordinates | `'x'` (from coordinate) | `Int64Index` |
| Without coordinates | `'x'` (from dimension) | `RangeIndex` |

**Key insight**: The Series index name always equals the dimension name. When a coordinate exists, the name comes from the coordinate; when no coordinate exists, the fallback explicitly sets `name=key`.
