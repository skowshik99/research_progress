### Index Collection
**Evidence:** `xarray/core/dataarray.py:2995`
```python
indexes = [self.get_index(dim) for dim in self.dims]
```
**Fact:** Indexes are collected by iterating over `self.dims` and calling `get_index()` for each dimension name.

### get_index() Behavior (Index Existence Check)
**Evidence:** `xarray/core/common.py:453-461`
```python
def get_index(self, key: Hashable) -> pd.Index:
    if key not in self.dims:
        raise KeyError(key)
    try:
        return self._indexes[key].to_pandas_index()
    except KeyError:
        return pd.Index(range(self.sizes[key]), name=key)
```

| Condition | Return Value |
|-----------|--------------|
| Index exists in `_indexes` | `self._indexes[key].to_pandas_index()` |
| Index doesn't exist | `pd.Index(range(self.sizes[key]), name=key)` |

**For `PandasIndex`** (line 343 of `indexes.py`): `to_pandas_index()` returns `self.index` (the underlying pandas Index).

### Series Index Name Relationship to dims
**Evidence from runtime probes:**

| Scenario | DataArray | Series Index Name | Index Type |
|----------|-----------|-------------------|------------|
| With coordinate | `coords={'x': array([0,1,2,3])}` | `'x'` | `Int64Index` |
| Without coordinate | No coords provided | `'x'` | `RangeIndex` |

**Fact:** The Series index name always equals the dimension name (`key`). When a coordinate exists, the pandas Index preserves that name. When no coordinate exists, the fallback creates a RangeIndex with `name=key`.
