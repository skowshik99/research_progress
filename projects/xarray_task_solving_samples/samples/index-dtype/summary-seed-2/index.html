### Why This Design?

The `pandas.Index` internally converts `float32` to `float64` (pandas default), but `coord_dtype` preserves the original dtype for:
1. **Type fidelity**: Maintains the user-specified dtype
2. **Operations**: Used in `create_variables()` to reconstruct Variables with correct dtype
3. **Concatenation**: Used in `concat()` via `np.result_type(*[idx.coord_dtype for idx in indexes])`

### Usage in `create_variables()`

```python
# xarray/core/indexes.py, line 341
data = PandasIndexingAdapter(self.index, dtype=self.coord_dtype)
var = IndexVariable(self.dim, data, attrs=attrs, encoding=encoding)
```

The `PandasIndexingAdapter` (lines 1412-1440) uses `self.coord_dtype` to ensure numpy conversions respect the preserved dtype.
