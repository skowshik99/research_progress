## 2. Important Notes and Learnings

### Key Finding: dtype Preservation Strategy

When `PandasIndex.from_variables()` is called with a Variable:

| Attribute | Value (float32 input) | Source |
|-----------|----------------------|--------|
| `Variable.dtype` | `float32` | User input |
| `PandasIndex.index.dtype` | `float64` | pandas.Index conversion |
| `PandasIndex.coord_dtype` | `float32` | Preserved from Variable |

**Critical Observation:** `PandasIndex.coord_dtype != PandasIndex.index.dtype` when the Variable has a non-default dtype.

### How `coord_dtype` is Determined and Stored

**Step 1:** In `PandasIndex.from_variables()` (`xarray/core/indexes.py`, lines 254-276):
```python
@classmethod
def from_variables(cls, variables: Mapping[Any, Variable]) -> PandasIndex:
    # ... validation ...
    name, var = next(iter(variables.items()))
    dim = var.dims[0]
    data = getattr(var._data, "array", var.data)
    
    # coord_dtype explicitly set to var.dtype
    obj = cls(data, dim, coord_dtype=var.dtype)
    obj.index.name = name
    return obj
```

**Step 2:** In `PandasIndex.__init__()` (`xarray/core/indexes.py`, lines 235-247):
```python
def __init__(self, array: Any, dim: Hashable, coord_dtype: Any = None):
    index = utils.safe_cast_to_index(array).copy()

    self.dim = dim
```

**Key Point:** When `from_variables()` is called, `coord_dtype` is **explicitly passed** as `var.dtype`, so it bypasses the `get_valid_numpy_dtype(index)` fallback.

### Relationship: `Variable.dtype` → `PandasIndex.coord_dtype`

### Branch Order and Fallback Conditions

```
PandasIndex.__init__(array, dim, coord_dtype=None):
  1. Create pandas.Index from array (may convert dtypes internally)
  2. IF coord_dtype is None:
     → coord_dtype = get_valid_numpy_dtype(index)
  3. ELSE:
     → coord_dtype = provided value (from var.dtype)
  4. Store: self.coord_dtype = coord_dtype
```

### Failure Conditions

- `PandasIndex.from_variables()` raises `ValueError` if:
  - More than one variable is provided
  - Variable is not 1-dimensional
- `get_valid_numpy_dtype()` returns `np.dtype("O")` for:
  - `pd.PeriodIndex`
  - Non-numpy dtypes (like pandas categories)
