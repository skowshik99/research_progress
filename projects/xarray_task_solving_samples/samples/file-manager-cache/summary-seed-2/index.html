## 2. Important Notes and Learnings

### The file_cache Fixture
```python
@pytest.fixture(params=[1, 2, 3, None])
def file_cache(request):
    maxsize = request.param
    if maxsize is None:
        yield {}  # No caching
    else:
        yield LRUCache(maxsize)  # Caching with capacity N
```

**Four parametrized values**:
| Value | Type | Behavior |
|-------|------|----------|
| `None` | `{}` (empty dict) | No caching; each acquire opens a new file |
| `1` | `LRUCache(1)` | Cache holds 1 file; second different key evicts first |
| `2` | `LRUCache(2)` | Cache holds 2 files; no eviction for 2 different keys |
| `3` | `LRUCache(3)` | Cache holds 3 files; no eviction for 3 different keys |

### LRUCache Implementation Details (step 2)
- Thread-safe using `threading.RLock`
- Uses `OrderedDict` internally for O(1) operations
- Evicts oldest items when `maxsize` is exceeded via `_enforce_size_limit()`
- `__setitem__` checks `if key in self._cache:` before deciding to evict or add

### Key Behavioral Patterns

**Cache Size Threshold Logic**:
```python
# From test_file_manager_write_consecutive:
assert (getattr(file_cache, "maxsize", float("inf")) > 1) == (f1a is f1b)
```
- `maxsize=1`: `1 > 1` is `False`, `f1a is f1b` is `False` → assertion passes (eviction works)
- `maxsize=2,3`: `maxsize > 1` is `True`, `f1a is f1b` is `True` → assertion passes (caching works)
- `maxsize=None`: `getattr(..., "maxsize", inf)` is `inf`, `inf > 1` is `True`, but `f1a is f1b` is `False` → assertion fails

**LRUCache Eviction Behavior**:
When `__setitem__` is called with a new key:
1. If key exists: update value, move to end (most recently used)
2. If key doesn't exist and `maxsize > 0`: evict oldest items if needed, then add new key
3. If key doesn't exist and `maxsize == 0`: call `on_evict` callback immediately
