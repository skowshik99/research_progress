**Four cache configurations tested:**
- `None` → `{}` (empty dict, no caching)

### LRUCache Implementation (Step 2)
- Thread-safe using `threading.RLock`
- Based on `OrderedDict` for LRU ordering
- `__setitem__` evicts oldest items when `maxsize` exceeded
- `maxsize` property is readable/writable
- When `maxsize == 0`, items are immediately evicted via `on_evict` callback

### Critical Behavior: Cache Size Threshold (Step 1, line 105-106)
```python
assert (getattr(file_cache, "maxsize", float("inf")) > 1) == (f1a is f1b)
```

**Branch outcomes:**
- `maxsize=1`: `1 > 1` is `False`; first file evicted when second manager acquired → `f1a is f1b` is `False` → assertion passes
- `maxsize=2,3`: `maxsize > 1` is `True`; file retained in cache → `f1a is f1b` is `True` → assertion passes
- `maxsize=None`: `inf > 1` is `True`; no cache means different file objects → `f1a is f1b` is `False` → assertion fails

### Why This Parametrization Matters
- **Eviction verification**: `maxsize=1` proves the cache correctly evicts after capacity
- **Caching verification**: `maxsize=2,3` prove files are retained and reused
- **No-cache baseline**: `None` ensures uncached behavior still works
- **Concurrency/safety**: All cache sizes tested for concurrent access and serialization
