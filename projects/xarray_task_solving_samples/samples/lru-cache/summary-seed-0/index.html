### OrderedDict Contract
- **Order semantics**: Oldest (front) → Newest (end)
- **`move_to_end(key)`**: Moves accessed key to the **end** (most recently used)
- **`popitem(last=False)`** (in `_enforce_size_limit`): Removes from **front** (least recently used)

### Thread Safety
- Uses `threading.RLock` (reentrant lock) for all dict operations
- Lock covers: `__getitem__`, `__setitem__`, `maxsize` setter
- `__iter__` and `__len__` do **not** acquire the lock

### Eviction Mechanism
```python
def _enforce_size_limit(self, capacity: int) -> None:
    while len(self._cache) > capacity:
        key, value = self._cache.popitem(last=False)  # Remove from front (oldest)
        if self._on_evict is not None:
            self._on_evict(key, value)
```

### Key Design Decisions
1. **`__iter__` creates a list copy** to prevent modification during iteration
2. **`__setitem__` handles existing keys** by deleting and re-inserting (moves to end)
3. **`maxsize` property** has a setter that enforces limits on resize
