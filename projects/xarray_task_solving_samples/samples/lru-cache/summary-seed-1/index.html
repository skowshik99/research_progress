### OrderedDict Order Semantics
- **Front (index 0)**: Oldest/least recently used
- **End (last index)**: Most recently used
- **Iteration order**: Docstring confirms "from the oldest to newest key"
- **Eviction**: `_enforce_size_limit()` uses `popitem(last=False)` to remove from front

### Lock Implementation
- Type: `threading.RLock()` (reentrant lock)
- Purpose: Thread-safe access to `_cache`
- All public operations (`__getitem__`, `__setitem__`, `maxsize.setter`) acquire the lock

### Eviction Mechanism
```python
def _enforce_size_limit(self, capacity: int) -> None:
    while len(self._cache) > capacity:
        key, value = self._cache.popitem(last=False)  # removes from front
        if self._on_evict is not None:
            self._on_evict(key, value)
```

### Priority Update Logic
When `cache['key']` is called:
1. Key position unchanged after lookup
2. `move_to_end(key)` marks key as recently used
3. Next eviction will target keys at the front (oldest)
