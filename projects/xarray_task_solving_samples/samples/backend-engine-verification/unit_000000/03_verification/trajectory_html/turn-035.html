## Core Function and Signature

- **Function**: `xarray.backends.api._get_default_engine(path: str, allow_remote: bool = False)` returns a literal engine name (`"netcdf4"` or `"scipy"` for local files; `"netcdf4"` or `"pydap"` for remote URIs).
- **Location**: `xarray/backends/api.py`, lines 131-137

## Decision Tree

```
_get_default_engine(path, allow_remote=False)
    ├─ if allow_remote and is_remote_uri(path):
    │     └─ return _get_default_engine_remote_uri()
    ├─ elif path.endswith(".gz"):
    │     └─ return _get_default_engine_gz()
    └─ else:
          └─ return _get_default_engine_netcdf()
```

## Remote URIs

- **Detection**: `xarray.core.utils.is_remote_uri(path)` uses regex `r"^[a-z][a-z0-9]*(\://|\:\:)"`
- **Supported schemes**: `http://`, `https://`, `ftp://`, `opendap://`, `s3://`, `gs://`, `file://`, and `http::/` (double colon)
- **Engine selection**:
  1. Tries to import `netCDF4`; if successful, returns `"netcdf4"`
  2. Fallback: tries to import `pydap`; if successful, returns `"pydap"`
  3. If both fail, raises `ValueError("netCDF4 or pydap is required for accessing remote datasets via OPeNDAP")`
- **Function**: `_get_default_engine_remote_uri()`, lines 83-100

## `.gz` Files

- **Trigger**: Any path ending with `.gz`
- **Engine selection**:
  1. Requires `scipy`. If present, returns `"scipy"`
  2. If missing, raises `ValueError("scipy is required for accessing .gz files")`
- **Function**: `_get_default_engine_gz()`, lines 102-110

## Standard netCDF Files

- **Trigger**: Paths that are neither remote URIs nor `.gz`
- **Engine selection**:
  1. Tries to import `netCDF4`; if present, returns `"netcdf4"`
  2. Fallback: tries to import `scipy.io.netcdf`; if present, returns `"scipy"`
  3. If both fail, raises `ValueError("cannot read or write netCDF files without netCDF4-python or scipy installed")`
- **Function**: `_get_default_engine_netcdf()`, lines 112-129

## Available Engines in the Codebase

- **Location**: `xarray/backends/api.py`, lines 58-67
- **ENGINES dictionary** maps engine names to backend entry points:
  - `"netcdf4"`, `"scipy"`, `"pydap"`, `"h5netcdf"`, `"pynio"`, `"pseudonetcdf"`, `"cfgrib"`, `"zarr"`
- **Note**: `_get_default_engine()` only considers `netcdf4`, `scipy`, and `pydap` depending on file type; other engines are not part of automatic selection.
